## 2. 版式代号表

每个代号对应 `layout-design.md` 中的一组坐标，**一一对应，不得自造代号**。

| 代号 | 用途 | 何时用 |
|---|---|---|
| `COVER` | 封面页 | 第 1 页固定 |
| `SECTION` | 章节过渡页 | 每 8–10 页插一个 |
| `BULLETS-3` | 3 条要点 | 内容较轻的页 |
| `BULLETS-4` | 4 条要点 | 默认要点页 |
| `BULLETS-5` | 5 条要点 | 信息密度上限 |
| `SPLIT-60-40` | 左文右图 | 60% 文字 40% 图表/配图 |
| `SPLIT-50-50` | 等分双栏 | 对比关系强的两栏 |
| `CHART-HERO` | 图表主视觉 | 有一张核心数据图 |
| `TABLE` | 表格页 | 需要精确数值或多项对比 |
| `QUOTE` | 大字金句 | 章节金句、转折点、结束语 |
| `CLOSING` | 结尾页 | 最后一页固定 |

### 代号 → 视觉类型合法性约束

| 代号 | 允许的视觉类型 |
|---|---|
| `COVER` / `SECTION` / `CLOSING` | `none` |
| `BULLETS-*` / `QUOTE` | `text` / `image` |
| `SPLIT-*` | 左 `text`，右 `chart` / `table` / `image` |
| `CHART-HERO` | `chart` |
| `TABLE` | `table` |

违反约束的组合是无效计划表。

## 3. 交接契约（计划表 → 生成脚本）

### 映射规则

1. **计划表第 N 行 = PPT 第 N 页**。顺序一致，不重排、不跳过。
2. **版式代号 → 坐标常量**：把 `layout-design.md` 对应版式的坐标写成 Python 常量字典，生成脚本按代号取用。
3. **视觉类型 → 对象类型**：
   - `chart` → `slide.shapes.add_chart(...)`，写入真实数据，保留可编辑嵌入工作簿
   - `table` → `slide.shapes.add_table(...)`，真实数值入单元格
   - `image` → `slide.shapes.add_picture(...)`，本地文件路径，不用网络 URL
   - `text` / `none` / `quote` → `slide.shapes.add_textbox(...)`
4. **演讲备注 → `notes_slide`**：该行「演讲备注要点」写入 `slide.notes_slide.notes_text_frame.text`。
5. **数据来源 → 页脚**：该行「数据/素材来源」在图表页写进 `数据来源` 位（11pt 浅灰），并汇总到末页。

### 建议的常量组织

```python
LAYOUTS = {
    "COVER": {
        "title":   (1.40, 2.30, 10.53, 1.60),
        "subtitle":(1.40, 4.00, 10.53, 0.70),
        "rule":    (1.40, 4.90, 2.50,  0.03),
        "meta":    (1.40, 5.20, 10.53, 0.45),
    },
    "BULLETS-4": {
        "title":   (0.6667, 0.50, 11.9999, 0.85),
        "kicker":  (0.6667, 1.35, 11.9999, 0.50),
        "bullets": [(0.6667, 2.05 + i*0.90, 11.9999, 0.75) for i in range(4)],
        "footer":  (0.6667, 6.95, 11.9999, 0.25),
    },
    # ... 其余代号
}
```

生成脚本放在会话工作目录 `output/<deck-name>/build_deck.py`，与产物同目录，不写入技能目录。

## 4. 最终验收清单

### 内容层
- [ ] Deck 回答了用户的核心问题，重点与语气适合确认过的受众
- [ ] 用户指定的必含内容全部落实，无跑题、无缺项
- [ ] 每页只承载一个信息角色，标题为结论式
- [ ] 页与页之间有逻辑承接，无重复页、无断层、无空白页
- [ ] 演讲备注已写入每一页，且非空

### 版面层
- [ ] 逐行核对 `layout-design.md` §7 四组检查清单全部通过
- [ ] 视觉类型与版式代号组合合法
- [ ] 安全区、字号层级、信息密度全部达标

### 数据层
- [ ] 每个数字都有来源，来源统一汇总
- [ ] 图表数据与页面结论一致
- [ ] 无占位符、无模板默认文案残留

### 交付层
- [ ] `check_office.py` 通过（ZIP/XML 完整、页数正确、关键文本命中）
- [ ] 备注抽查脚本返回空缺页列表（`check_office.py` 不读备注，必须另查）
- [ ] 渲染预览逐页核对无溢出、遮挡、裁切
- [ ] 首尾页非空白
- [ ] 已用 `present` 交付最终 .pptx

### 备注抽查命令

```python
from pptx import Presentation
p = Presentation("<deck>.pptx")
missing = [i for i, s in enumerate(p.slides, 1)
           if not s.notes_slide.notes_text_frame.text.strip()]
print("缺备注页:", missing)   # 期望 []
```
