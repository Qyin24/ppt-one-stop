# 第 4 步 · 版面设计规范

本文件是 `ppt-one-stop` 独有的规范，填补 `ppt-content-generation`（内容方法论）与 `ppt-visual-design`（配色排版方法论）之间的空白：**逐页决定配什么图/表/图表、用什么版式、字号取多少、元素落在哪里**。

所有数值都是确定值。不要写「适当」「合理」「尽量」这类无法执行的描述。

---

## 1. 画布与安全边距

### 基准尺寸

16:9 标准画布，**精确锁定**：

```python
from pptx.util import Emu
prs.slide_width  = Emu(12192000)   # 13.333in
prs.slide_height = Emu(6858000)    # 7.5in
```

> python-pptx 默认是 `10 × 7.5in`（4:3），**必须显式覆盖**。
> 不要用 `Inches(13.333)`——它等于 12191695 EMU，比标准值少 305 EMU，会让网格对齐变成假精度。

### 纵向区域带

| 区域 | 起点 | 终点 | 高度 | 内容 |
|---|---|---|---|---|
| 标题带 | 0.50in | 1.35in | 0.85in | 页标题，单行 32pt / 双行 28pt |
| 结论句带 | 1.35in | 1.85in | 0.50in | 「所以呢」一句话，18–20pt，强调色 |
| **内容区** | 1.95in | 6.85in | **4.90in** | 所有正文 / 图 / 表 **只能落在此区内** |
| 页脚带 | 6.95in | 7.10in | 0.15in | 12pt 浅灰，页码 + 数据来源 |

### 安全框

```
x ∈ [0.6667, 12.6667] in     # 左右各 5% 页宽
y ∈ [0.3750,  7.1250] in     # 上下各 5% 页高
```

任何形状不得越出此框。溢出即为不合格。

> **页脚带必须落在安全框内**。安全框下界是 `y = 7.125`，所以页脚元素取
> `top = 6.95in`、`height = 0.15in`（`6.95 + 0.15 = 7.10 < 7.125`）。
> 不要按「上下留白要更宽松」把页脚做到 0.25in 高——那样底部会越界。

### 12 列网格

```
安全框净宽 = 13.3333 − 2 × 0.6667 = 11.9999 in
列间距 gutter = 0.20 in
单列宽 = (11.9999 − 11 × 0.20) / 12 = 0.8167 in
```

常用跨列与其宽度：

| 跨列 | 宽度 (in) | 用途 |
|---|---|---|
| 全宽 12 列 | 11.9999 | 表格、主视觉大图 |
| 8 列 | 6.7663 | 图 + 要点分栏 |
| 7 列 | 5.9496 | 60/40 分栏的左栏 |
| 6 列 | 5.1329 | 50/50 分栏 |
| 5 列 | 4.3162 | 60/40 分栏的右栏 |
| 4 列 | 3.4995 | 三分栏 |
| 3 列 | 2.6829 | 四分栏 |

第 N 列起点公式：`0.6667 + N × (0.8167 + 0.20)`

## 2. 字号层级表

| 角色 | 字号 | 字重 | 颜色角色 |
|---|---|---|---|
| 封面主标题 | 44–54pt | Bold | 主色或近黑 |
| 封面副标题 | 20–24pt | Regular | 次要灰 |
| 章节页标题 | 40pt | Bold | 主色 |
| 页标题 | 32pt（双行降为 28pt） | Bold | 主文本色 |
| 结论句 | 18–20pt | Medium | 强调色 |
| 一级要点 | 18–20pt | Regular | 主文本色 |
| 二级说明 | 15–16pt | Regular | 次要灰 |
| 图表轴标签 / 数据标签 | 12–14pt | Regular | 次要灰 |
| 数据来源 / 页脚 | 10–11pt | Light | 辅助浅灰 |

**硬性规则**
- 最小字号 **12pt**（投影可读下限）；稳妥用 14pt。
- 相邻层级差 ≥ **4pt**。
- 不跨级使用（例如不出现 32pt 直接跳到 12pt 而没有中间层）。
- 全篇字体 **≤2 种**（标题一种 + 正文一种）。

### 中文字体替换

`ppt-visual-design` 推荐的是 Montserrat / Roboto / Open Sans 等**纯西文字体**，中文 PPT 不能直接套用。按下表替换：

| 用途 | 字体 |
|---|---|
| 标题 | 思源黑体（无则用微软雅黑 Bold） |
| 正文 | 微软雅黑 |
| 引文 / 数据强调 | 思源宋体（无则用宋体） |

> **关键**：`run.font.name = "微软雅黑"` 只写入 `<a:latin>`，中文字符**不会**生效。必须额外注入 `<a:ea>`：
> ```python
> from pptx.oxml.ns import qn
> rPr = run._r.get_or_add_rPr()
> rPr.append(rPr.makeelement(qn('a:ea'), {'typeface': '微软雅黑'}))
> ```

## 3. 元素间距与对齐

| 关系 | 间距 |
|---|---|
| 同组元素之间 | 0.12–0.20in |
| 不同组之间 | 0.30–0.40in |
| 标题与其下分隔线 | 0.15in |
| 结论句与内容区 | 0.10in |

**对齐基准**
- 所有正文块左边缘对齐到同一 x（通常是 0.6667in 或网格列起点）。
- 卡片、图表、表格宽度取网格整数倍，不随手取整。
- 行距 1.2–1.5 倍。
- 要点条目之间靠 **0.15in 间距**分隔，**不用空行**。

## 4. 版式决策表 · 每一页配什么图/表/图表

按「这一页要说服什么」选择视觉形态：

| 表达意图 | 首选 | 备选 | 禁忌 |
|---|---|---|---|
| 展示量级差异 | 柱状图 / 条形图 | 数字大字卡片 | 饼图 |
| 展示时间趋势 | 折线图 | 面积图、瀑布图 | 3D 柱状图 |
| 展示构成占比 | 堆叠条 / 环形（≤5 类） | 表格 | 超过 5 类的饼图 |
| 展示精确数值 | 表格 | 条形图 + 数据标签 | 只有图没有数字 |
| 展示步骤流程 | 编号步骤块 + 单向箭头 | 流程图 | 箭头交叉、乱指 |
| 展示因果影响 | 因果链 + 前后对比双栏 | Before/After 双栏 | 只罗列现象不给因果 |
| 展示现场/场景 | 全幅照片（≥1920×1080） | 半幅图 + 要点 | 低分辨率拉伸 |
| 展示层级 | 树状图 / 金字塔（≤3 层） | 表格 | 深层圆环 |
| 展示关系网络 | 关系图（≤7 节点） | 矩阵表 | 12+ 节点毛球 |
| 无数据可配 | 纯文字版式 | 大字金句页 | 硬凑装饰图 |

### 配套硬规则

1. **一页一个视觉主张**。一页塞两种图表等于没重点。
2. **图表标题写结论，不写维度**。
   - ✅ 「华东贡献 62% 的增量收入」
   - ❌ 「各区域收入对比」
3. **图表必须带数据标签或明确的数据来源脚注**。
4. 图片等比裁切不拉伸；全篇色调统一；同一张图不得重复使用。
5. 没有真实素材且不能生图时，改用无图版式。**绝不放假图或占位文字。**
6. 图表用 python-pptx 原生 `add_chart`（保留可编辑的嵌入工作簿），不贴图片。

## 5. 版面分配与信息密度

| 约束 | 数值 |
|---|---|
| 每页信息角色数 | 1 |
| 连续纯文字页上限 | 3 页（之后插图表页或图片页） |
| 单页要点数 | ≤ 5 条，每条 ≤ 2 行 |
| 表格规模 | ≤ 7 行 × 5 列 |
| 图表类目数 | ≤ 7 个 |
| 章节过渡页间隔 | 每 8–10 页插一个 |
| 正文页讲解时长 | 约 1 分钟 / 页 |
| 封面与章节页时长 | 20–30 秒 |

**页数换算**：总时长（分钟）≈ 正文页数 × 1 + 章节页数 × 0.4

## 7. 版面检查清单（渲染前逐项自检）

### A. 安全区
- [ ] 所有形状落在 `x∈[0.6667,12.6667]`、`y∈[0.375,7.125]` 内
- [ ] 所有正文/图/表落在内容区 `1.95–6.85in`
- [ ] 宽度取网格整数倍
- [ ] 无越界、无重叠、无元素贴边

### B. 字号
- [ ] 最小字号 ≥12pt
- [ ] 相邻层级差 ≥4pt
- [ ] 全篇字体 ≤2 种
- [ ] 中文字体已注入 `<a:ea>`
- [ ] 文字与背景对比度 ≥4.5:1

### C. 密度
- [ ] 单页要点 ≤5 条，每条 ≤2 行
- [ ] 无超长段落
- [ ] 表格 ≤7 行 × 5 列
- [ ] 图表类目 ≤7 个，带数据标签
- [ ] 连续纯文字页 ≤3 页

### D. 数据
- [ ] 每个数字都有来源
- [ ] 数据来源统一收进末页 + 图表页脚注
- [ ] 无占位符残留（如 Lorem、XXX、待补充）
- [ ] 无模板默认文案残留（如「感谢阅读」「Key Metrics」「AI Capital」）
- [ ] 图片真实存在且分辨率 ≥1920×1080，同图未重复使用
